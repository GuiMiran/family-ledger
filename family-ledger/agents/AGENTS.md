# Agents

## Receipt Agent
Lee tickets y estructura la información.

## OCR Agent
Extrae texto de imágenes.

## Product Agent
Normaliza nombres de productos.

## Inventory Agent
Actualiza despensa, nevera y congelador.

## Conservation Agent
Recomienda cómo guardar cada alimento.

## Savings Agent
Calcula ahorro, comparativas y ROI.

## Waste Agent
Detecta riesgo de desperdicio.

## Meal Planner Agent
Propone menús con productos disponibles.

## Forecast Agent
Predice cuándo se agotarán productos.

## Shopping Agent
Genera listas de compra inteligentes.
