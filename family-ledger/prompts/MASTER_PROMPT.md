# Master Prompt - FAMILY LEDGER

Desarrolla FAMILY LEDGER usando Spec Driven Development.

Antes de generar código, crea o actualiza:

1. spec
2. acceptance criteria
3. test plan
4. architecture decision record

Solo después genera implementación.

La app debe aceptar fotos de tickets como input principal y convertirlas en datos estructurados, inventario, ahorro, conservación y recomendaciones.
