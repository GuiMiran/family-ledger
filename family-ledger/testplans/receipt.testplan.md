# Receipt Test Plan

## Scope

Validar extracción de tickets.

## Test Cases

1. Ticket Makro legible.
2. Ticket con IVA.
3. Ticket con descuentos.
4. Ticket parcialmente borroso.
5. Producto con peso variable.
6. Producto con precio por kilo.

## Expected Result

El sistema extrae datos o solicita confirmación solo de campos ambiguos.
