# FAMILY LEDGER

**AI Powered Household Intelligence**

> Cada euro tiene un propósito.

FAMILY LEDGER es una aplicación familiar desarrollada con **Spec Driven Development (SDD)** para convertir fotos de tickets en inteligencia de ahorro, inventario, conservación y planificación de comidas.

## Objetivo

No es una app de gastos. Es un sistema operativo financiero y alimentario para una familia.

## Input principal

El usuario hace una foto al ticket. La aplicación extrae productos, precios, cantidades, IVA, descuentos y supermercado mediante OCR e IA.

## Dominios principales

- Purchase Intelligence
- Inventory
- Food Lifecycle
- Savings Engine
- Meal Planner
- Analytics
- Family AI

## Principios SDD

1. Primero la visión.
2. Después las especificaciones.
3. Luego criterios de aceptación.
4. Después test plans.
5. Finalmente implementación.

Nada se implementa sin una especificación aprobada.
